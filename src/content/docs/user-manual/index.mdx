The user manual is organised by what you are trying to do, not by menu. Each chapter explains how the tools for one job fit together, and links to the [command reference](/reference/) for every detail of each command.

New to Musa CAD? Start with [Your first drawing](/get-started/first-drawing/), then read the chapters in order. Each one builds on the one before.
