**The short answer:** most of what your hands already know works in Musa CAD. Type `L` and you draw a line. Press <kbd>F8</kbd> and ortho turns on. Every edit command starts with `Select objects:`. This page goes through the details: what carries over, where Musa CAD goes further, what is different, and what is not there yet.

It is marked partial because a command-by-command comparison will come from the [command reference](/reference/). As each command page is written, it will list its own differences from AutoCAD.

## What works the same

| Your habit | In Musa CAD |
|---|---|
| **Typing commands and aliases** | The same names and aliases: `L`, `C`, `PL`, `A`, `REC`, `E`, `M`, `CO`, `RO`, `SC`, `MI`, `O`, `TR`, `EX`, `F`, `CHA`, `H`, `DLI`, `MT`, `B`, `I`, `X`, `LA`, `Z`, `U` and the rest. Capital or small letters both work, and a list of matches appears as you type. |
| **The prompts** | `Specify next point or [Close/Undo]:` and so on, with the same options. Options are in square brackets, the default is in angle brackets. <kbd>Enter</kbd> repeats the last command, <kbd>Esc</kbd> cancels. |
| **Selecting objects** | Click to pick. Drag left-to-right for a window, right-to-left for a crossing. Press and drag for a lasso. <kbd>Shift</kbd>+click removes an object. <kbd>Ctrl</kbd>+<kbd>A</kbd> selects everything. At `Select objects:` you can type Window, Crossing, Fence, WPolygon, CPolygon, ALL, Last, Previous, Add, Remove, Undo and the other keywords. Selecting first and then running a command also works. |
| **Coordinates** | `10,20`, `@30,0` (relative), `@30<45` (polar), and `#` for absolute inside Dynamic Input. Feet, inches and fractions work at every prompt. |
| **The ribbon** | Home, Insert, Annotate, Parametric, View, Manage and Output, with AutoCAD's panels in AutoCAD's places. |
| **Function keys** | <kbd>F3</kbd> object snap, <kbd>F7</kbd> grid, <kbd>F8</kbd> ortho, <kbd>F9</kbd> snap, <kbd>F10</kbd> polar, <kbd>F11</kbd> object snap tracking, <kbd>F12</kbd> Dynamic Input. <kbd>Ctrl</kbd>+<kbd>Z</kbd> and <kbd>Ctrl</kbd>+<kbd>Y</kbd> undo and redo. |
| **Object snaps** | Running snaps, and one-off snaps typed at a prompt: `END`, `MID`, `CEN`, `INT`, `TAN`, `PER`, `EXT`, `NEA`, `QUA`, `NOD`, `INS`, `APP`, `PAR`, `GCEN`, `NON`. Also `FROM`, `M2P`, `TT`, `TK`, the <kbd>Shift</kbd>+right-click snap menu, and the <kbd>Shift</kbd> override keys. |
| **Grips** | Every object has grips. Drag them to stretch or move; dimensions have a grip on their text. |
| **Layers and properties** | The Layer Properties Manager with layer states and filters; `-LAYER` at the command line; LAYISO, LAYOFF, LAYFRZ and the other layer tools; ByLayer and ByBlock. |
| **Blocks** | BLOCK, WBLOCK, INSERT, the Block Editor (BEDIT), attributes (ATTDEF, EATTEDIT, BATTMAN, ATTSYNC), REFEDIT, external references (XREF) and images. |
| **Dimensions** | Linear, aligned, angular, radius, diameter, jogged, ordinate and arc length; DIMCONTINUE, DIMBASELINE and QDIM; DIMEDIT, DIMTEDIT, DIMSPACE and DIMBREAK; dimensions that follow the objects they measure; the Dimension Style Manager and the DIM variables. |
| **Text, leaders and tables** | TEXT with all fifteen justifications, MTEXT and text styles; LEADER, QLEADER and MLEADER with styles; TABLE with styles and links to CSV and Excel files. |
| **Layouts and plotting** | Layouts, viewports, MSPACE and PSPACE, page setups, PLOT to PDF or a printer, PREVIEW, PUBLISH and EXPORTPDF. Plot styles are colour-based (CTB): none, monochrome or grayscale. |
| **Measuring** | DIST, ID, AREA, LIST, MEASUREGEOM, MASSPROP, TIME, STATUS, CAL and QUICKCALC. |
| **Your aliases** | ALIASEDIT can load your `acad.pgp` file. |
| **Your shortcuts** | CUI lets you give any command a key, and warns you if the key is already taken. |
| **Express Tools** | Many of them: TEXTMASK, TXTEXP, TCOUNT, TEXTFIT, BURST, GATTE, EXTRIM, NCOPY, MOCORO, FLATTEN, VPSYNC, VPSCALE, XLIST, ATTOUT, ATTIN, MPEDIT, DIMEX, DIMIM, TFRAMES. |

## Where Musa CAD goes further

- **Dynamic Input is on from the start, and it does everything at the cursor.** You type commands, read prompts, pick options with the down arrow and type exact lengths, all next to your cursor. Many AutoCAD users turn Dynamic Input off; in Musa CAD it is the main way to work, and the classic command line is one <kbd>F12</kbd> away. [See how it works](/user-manual/dynamic-input/).
- **Drawings can be made entirely by programs.** A `.musa` drawing is a plain text file that any script can write. The `musacad` command checks it and prints it to PDF with no window, so it runs in scripts, on servers and with AI agents. The [fabrication pipeline](https://github.com/MusaCAD/fabrication_pipeline) uses this to turn 3D models into finished fabrication drawings with no hand drafting. [See Scripting and automation](/scripting/).
- **Drawings can be checked automatically.** `musacad --check` finds text that overlaps other text, text that runs outside the sheet's border, and characters the font cannot draw, before a drawing goes out.
- **It runs on Linux,** including from Flathub.
- **No account, no licence and no tracking.** The only thing it does online is a once-a-day check for a new version, which you can turn off, and downloading the DWG converter when you ask it to.

## What is different

- **The native format is `.musa`, not DWG.** It is a readable text file. DXF is read and written directly. DWG goes through the free ODA File Converter, which Musa CAD downloads for you from **DWG Setup**. When a file is imported, Musa CAD tells you anything it could not bring across, rather than dropping it silently.
- **The interface is dark,** dialogs included.
- **Fonts:** text uses Musa CAD's built-in line font or any TrueType or OpenType font on your computer. SHX font files are not read; a drawing that asks for one gets a close substitute, and Musa CAD says which.
- **New releases change the file format.** A file saved by a newer version needs that version or newer to open. Older files always open.

## What is not there yet

- **3D.** Musa CAD is for 2D only.
- **AutoLISP, VBA, .NET and ObjectARX.** None of these run inside Musa CAD. Automation is done from outside, by programs that write drawings and call the `musacad` command. For many jobs this goes further than a LISP routine: it can build a whole drawing set. See [Scripting and automation](/scripting/).
- **Parametric constraints.** The Parametric tab is there, but its buttons are greyed out, and each tooltip says the tool is not built yet.
- **Sheet sets, dynamic blocks, annotative objects, named plot styles (STB) and real SHX fonts** are not in version 0.8.0.
- **Every last option.** Most draw, modify and annotate commands follow AutoCAD option for option, but some settings are still to come. The source repository's [COMMANDS.md](https://github.com/MusaCAD/MusaCAD/blob/main/docs/COMMANDS.md) tracks every command, and [AUTOCAD_CONFIG.md](https://github.com/MusaCAD/MusaCAD/blob/main/docs/AUTOCAD_CONFIG.md) tracks the dimension style and options settings one by one.

## Bring your work across

<Steps>

1. **Your files.** Open DXF files directly. For DWG, open **DWG Setup** once and let it download the converter, then use **File ▸ Import ▸ DWG…**. Read the import message: it lists anything that could not be brought across.

2. **Your aliases.** Type `ALIASEDIT` and load your `acad.pgp`.

3. **Your keyboard shortcuts.** Type `CUI` and set the keys you are used to.

4. **Your habits.** Nothing to do. Type `L` and draw a line.

</Steps>
