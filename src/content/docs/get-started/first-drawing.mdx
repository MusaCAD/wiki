In about ten minutes you will draw the plate below: 120 units wide, 80 high, with two round holes and two dimensions. Then you will save it and print it to a PDF. Each step shows exactly what Musa CAD asks and what you type, so you can follow along.

<Figure id="first-part" alt="A rectangular plate, 120 wide by 80 high, drawn in outline, with two round holes of radius 10 at its left and right thirds. A horizontal dimension under the plate reads 120.00 and a vertical dimension on its left reads 80.00." caption="The finished drawing, printed to an A4 sheet by Musa CAD." eager />

## Before you start

- Musa CAD opens with an empty drawing called **Drawing1**. Think of one unit as one millimetre.
- **Just start typing.** You do not need to click anywhere first. What you type appears next to your cursor, and so do Musa CAD's questions (the *prompts*). This is called Dynamic Input. If you prefer a command line at the bottom of the window, press <kbd>F12</kbd>.
- <kbd>Enter</kbd> or <kbd>Space</kbd> confirms what you typed. <kbd>Esc</kbd> cancels. In the boxes below, `↵` means "press Enter".
- Roll the mouse wheel to zoom in and out. Hold the middle button and drag to move around (pan).

## Draw the plate

<Steps>

1. Type `REC` and press <kbd>Enter</kbd>. This starts the RECTANG command. Type the first corner, then the second corner. The `@` means "measured from the last point":

   ```musacad
   Command: REC
   Specify first corner point or [Chamfer/Elevation/Fillet/Thickness/Width]: 0,0
   Specify other corner point or [Area/Dimensions/Rotation]: @120,80
   ```

   :::tip[The same thing with Dynamic Input]
   After the first corner, move the mouse up and to the right. Two boxes appear beside the rectangle, showing its width and its height. Type `120`, press <kbd>Tab</kbd>, type `80`, and press <kbd>Enter</kbd>.
   :::

   If the rectangle is too small to see, type `Z`, press <kbd>Enter</kbd>, then type `E` and press <kbd>Enter</kbd>. This zooms to fit everything (Zoom Extents).

2. Draw the first hole. Type `C` for CIRCLE, give the centre, then the radius:

   ```musacad
   Command: C
   Specify center point for circle or [3P/2P/Ttr (tan tan radius)]: 30,40
   Specify radius of circle or [Diameter]: 10
   ```

3. Draw the second hole. Musa CAD remembers the last radius and offers it in angle brackets, so you only need to press <kbd>Enter</kbd>:

   ```musacad
   Command: C
   Specify center point for circle or [3P/2P/Ttr (tan tan radius)]: 90,40
   Specify radius of circle or [Diameter] <10.0000>: ↵
   ```

</Steps>

**Tip:** pressing <kbd>Enter</kbd> when no command is running repeats the last command. That is a quick way to start the second circle without typing `C` again.

## Add the dimensions

<Steps>

1. Type `DLI` for DIMLINEAR. It asks for the two points to measure between, then where to put the dimension line. You can type the points, or hover over a corner until the Endpoint snap marker appears and click:

   ```musacad
   Command: DLI
   Specify first extension line origin or <select object>: 0,0
   Specify second extension line origin: 120,0
   Specify dimension line location or [Mtext/Text/Angle/Horizontal/Vertical/Rotated]: 60,-15
   ```

   The dimension shows the width, 120. Musa CAD measures it from the two points, so the number is always right, even if you change the plate later.

2. Now the height, on the left side. Musa CAD works out whether the dimension is horizontal or vertical from where you put the dimension line:

   ```musacad
   Command: DLI
   Specify first extension line origin or <select object>: 0,0
   Specify second extension line origin: 0,80
   Specify dimension line location or [Mtext/Text/Angle/Horizontal/Vertical/Rotated]: -15,40
   ```

</Steps>

Made a mistake? Press <kbd>Ctrl</kbd>+<kbd>Z</kbd> to undo. To move a dimension's text, click the dimension, then drag the small square on its text.

## Save it

Press <kbd>Ctrl</kbd>+<kbd>S</kbd>. Because the drawing has never been saved, the Save window opens with the file type **Musa CAD (*.musa)**. Name it `first-part.musa`. The tab at the top now shows the file name. From now on <kbd>Ctrl</kbd>+<kbd>S</kbd> saves straight away, and <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> is Save As.

A `.musa` file is Musa CAD's own format. It is plain text, so you can even open it in a text editor. Files saved by version 0.8.0 need 0.8.0 or newer to open. Older files always open in newer versions.

## Print it to PDF

Press <kbd>Ctrl</kbd>+<kbd>P</kbd>, or type `PLOT`. In the Plot window, choose:

- **Printer/plotter:** PDF File…
- **Paper size:** A4, **Orientation:** Landscape
- **Plot area:** Extents (the whole drawing)
- **Scale:** Fit to paper. For a real drawing you would pick a fixed scale instead.
- **Plot style (CTB):** Monochrome (all black), which is how a workshop usually wants a drawing.

Click **Preview…** to check the sheet, then **Plot** and choose where to save the PDF. The PDF is made of real lines, not pixels, so it stays sharp however far you zoom in.

You can also print it without opening Musa CAD at all. The picture at the top of this page was made exactly that way:

```sh
musacad --plot first-part.musa first-part.pdf --paper A4 --landscape --monochrome
```

## What you learned

- Start commands by typing their short names: `REC`, `C`, `DLI`, `Z`.
- Read the prompt: options are in `[square brackets]`, the default is in `<angle brackets>`, and <kbd>Enter</kbd> accepts it.
- Type exact points: `30,40` is a point on the drawing, `@120,80` is measured from the last point, and `@50<45` means 50 units at 45 degrees.
- Dimensions measure the drawing; you never type their numbers.
- Save as `.musa`, print to PDF.
