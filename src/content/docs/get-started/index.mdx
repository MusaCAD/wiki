## Before you install

Musa CAD's drawing area needs a graphics driver with **OpenGL 4.5 Core**. Current drivers for Intel, AMD and NVIDIA on Windows and Linux have it. macOS does not, which is why the macOS build is a preview with the command line only. If the viewport cannot be created, the application says what it found and what it needs at startup instead of showing a black window.
