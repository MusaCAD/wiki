The **experimental 0.9.0-1 build** can open the drawing window on macOS. It uses an OpenGL 4.1 rendering path. A Mac tester has [confirmed that the app opens](https://github.com/MusaCAD/MusaCAD/issues/2#issuecomment-6879777908); drawing, editing and plotting still need wider testing on physical Macs.

This download is a separate prerelease. The regular 0.9.0 release has Windows and Linux packages, so use the link below for the Mac build.

## What you need

- An **Apple silicon Mac** (M1 or later).
- **macOS 12 or later**.

This build does not support Intel Macs. Test with copies of drawings while the Mac build is experimental.

## Download and install

1. Open the [experimental Mac release](https://github.com/MusaCAD/MusaCAD/releases/tag/macos-experimental-0.9.0-1).
2. Download `MusaCAD-0.9.0-arm64.dmg` and `MusaCAD-0.9.0-arm64.dmg.sha256` to the same folder.
3. In Terminal, change to that folder and check the download:

   ```sh
   cd ~/Downloads
   shasum -a 256 -c MusaCAD-0.9.0-arm64.dmg.sha256
   ```

   Continue only if the result says `OK`.
4. Open the disk image and drag `MusaCAD.app` into **Applications**.
5. Start the app from Applications.

## If macOS blocks it

The app is ad-hoc signed but is **not notarized by Apple**. After checking the download, open **System Settings ▸ Privacy & Security** and choose **Open Anyway** if offered. Then try opening the app again. There is no need to disable Gatekeeper for the whole computer.

## Try a drawing

Create a small drawing, use LINE and CIRCLE, enter a length with Dynamic Input, and try zooming and panning. Save it, reopen it and export a PDF. Keep the originals of any existing drawings you test.

Report launch problems, incorrect drawing, missing icons or crashes in [issue #2](https://github.com/MusaCAD/MusaCAD/issues/2). Include your Mac model, macOS version, the steps that show the problem and a screenshot or sample drawing where possible.

## Use the command line

The executable is inside the application bundle:

```sh
/Applications/MusaCAD.app/Contents/MacOS/musacad_app --version
/Applications/MusaCAD.app/Contents/MacOS/musacad_app --check part.musa
/Applications/MusaCAD.app/Contents/MacOS/musacad_app --plot part.musa part.pdf --paper A4
```

The app reports `Musa CAD 0.9.0`; include the full release name **macos-experimental-0.9.0-1** when reporting a problem. The [command line guide](/scripting/command-line/) explains the options.

## Updates

The regular update check follows stable releases. Check the [Mac release page](https://github.com/MusaCAD/MusaCAD/releases/tag/macos-experimental-0.9.0-1) and [issue #2](https://github.com/MusaCAD/MusaCAD/issues/2) for experimental Mac updates.
