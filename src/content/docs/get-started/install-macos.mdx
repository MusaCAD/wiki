:::caution[Please read this first]
On a Mac, Musa CAD's drawing area does not open yet. The drawing area needs OpenGL 4.5, and macOS stops at OpenGL 4.1. When you start the app, it shows a message explaining this and closes. Mac support is tracked in [issue #2](https://github.com/MusaCAD/MusaCAD/issues/2).
:::

What does work on a Mac is the command line. You can check drawings and print them to PDF without opening a window, which is useful for scripts and automation.

## What you get

Each release page has a disk image for Apple silicon Macs, `MusaCAD-<version>-arm64.dmg`. It contains `MusaCAD.app`.

## Install it

1. Download the disk image from the [latest release](https://github.com/MusaCAD/MusaCAD/releases/latest) and open it.
2. Drag `MusaCAD.app` into Applications.
3. If macOS refuses to open it because it cannot check the developer, right-click the app and choose **Open** once.

## Use the command line

The program sits inside the app bundle:

```sh
/Applications/MusaCAD.app/Contents/MacOS/musacad_app --version
/Applications/MusaCAD.app/Contents/MacOS/musacad_app --check part.musa
/Applications/MusaCAD.app/Contents/MacOS/musacad_app --plot part.musa part.pdf --paper A4
```

It works exactly as on Windows and Linux. The [command line page](/scripting/command-line/) explains every option.

## When will the drawing area work?

The drawing area needs a second graphics back end, either Metal or a simpler OpenGL 4.1 path. The code is already split so that one can be added. When it lands, the release notes and this page will say so.
