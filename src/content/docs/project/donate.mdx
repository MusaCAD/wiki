Musa CAD is free, and it stays free. If it saves you time or money, here is how you can help keep it going.

## Donate

Donations buy development time: new features, faster drawing and more tested releases.

| Method | Where |
|---|---|
| Ko-fi | [ko-fi.com/pranaykiran](https://ko-fi.com/pranaykiran) |
| PayPal | [paypal.me/pranaykiran](https://paypal.me/pranaykiran) |
| UPI (India) | `kiranpranay12@okicici` |

The [donate page on the main website](https://musacad.org/donate/) has a UPI QR code you can scan. Donations are voluntary gifts. They do not buy support or a say in the project.

## Other ways to help

- **Report bugs.** A clear bug report is one of the most useful things you can give. See [How to report a bug](/troubleshooting/bug-reports/).
- **Improve this wiki.** Every page has an **Edit page** link. Command pages that only list facts need a plain explanation and an example.
- **Contribute code.** See [Contributing](/developer/contributing/).
- **Star the project** on [GitHub](https://github.com/MusaCAD/MusaCAD), and tell people who draw in 2D that Musa CAD exists.
