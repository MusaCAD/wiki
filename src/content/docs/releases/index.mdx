## Upgrading

Upgrading is safe for your drawings: **a newer Musa CAD always opens files from an older one.** Two things to know:

- **Files saved by a newer release may not open in an older one.** When a release changes the file format, its page says so. If you share drawings with someone on an older version, either both upgrade, or send them a DXF, which every version reads.
- **Your settings carry over.** Your shortcuts, aliases, workspaces and preferences are kept when you upgrade.

How to upgrade:

| You installed from | To upgrade |
|---|---|
| Flathub | It updates with your other apps, or run `flatpak update org.musacad.MusaCAD`. |
| The Windows installer | Click the update notice in the status bar; the Update window downloads and installs the new version. Or run the new installer over the old one. |
| The AppImage | Download the new AppImage and use it instead of the old one. |
| The Flatpak file | Install the new file with `flatpak install --user`. |
| Source | `git pull`, then build again. |

Musa CAD checks once a day whether a new release is out, and says so in the status bar. You can turn that off in **Options** (`OP`).
