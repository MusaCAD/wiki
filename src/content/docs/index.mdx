## How this wiki stays true

Every page says which release it was last checked against and whether it is complete, partial or a stub. A page that falls behind a release says so at the top. The data on command pages comes from the application itself, not from a hand-written table, and the illustrations of drawings are plotted by the application at build time from the example files you can download. Where the wiki does not yet cover something, it says "not documented yet" rather than guessing.

Nothing here is taken from Autodesk's documentation. Every description is written from Musa CAD's own source, its own prompts and testing.
