## What makes Musa CAD different

<CardGrid>
  <Card title="Type where you draw">
    With Dynamic Input, the command, the prompt and the exact length or angle all appear next to your cursor. You type the number there and keep your eyes on the drawing. It is on from the first start. [How Dynamic Input works](/user-manual/dynamic-input/)
  </Card>
  <Card title="Automate whole drawings">
    A Musa CAD drawing is a plain text file that any program can write, and the `musacad` command checks and prints drawings without opening a window. Scripts and AI agents can produce finished drawing sets. [Scripting and automation](/scripting/)
  </Card>
  <Card title="Open the files you already have">
    Musa CAD reads and writes DXF directly. It opens and saves DWG through the free ODA File Converter, which it downloads for you in one click.
  </Card>
  <Card title="Free, open source, no account">
    It runs on Windows and Linux, with a macOS preview. There is no licence key, no sign-in and no subscription.
  </Card>
</CardGrid>

## How to read this wiki

Every page tells you how far to trust it, just under its title:

- **Complete** means the page covers its topic.
- **Partial** means it covers part of it, and says what is missing.
- **Not written yet** means the page only shows what Musa CAD itself reports, such as a command's name, shortcut and first prompt.
- **Checked against Musa CAD 0.8.0** is the release the page was last tested with. If a newer release comes out and the page has not been checked again, a note at the top says so.

The command lists and the pictures of drawings are made by Musa CAD itself whenever the wiki is built, so they always match the release it was built for.

Nothing here is copied from Autodesk's documentation. Every page is written from Musa CAD's own source code, its own prompts and real use.
