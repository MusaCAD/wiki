Musa CAD is built so that programs can do everything a drafter does at the keyboard: create a drawing, check it, and print it. You can generate a part drawing from a spreadsheet, plot a whole drawing set every night, check every drawing in a repository before it goes out, or let an AI agent draft a complete set of fabrication drawings from a 3D model.

## How it works

Automation in Musa CAD rests on four simple pieces.

1. **Drawings are plain text.** A `.musa` file is a list of readable records, one object per line: `LINE 0 0 120 0 ...`, `CIRCLE 30 40 10 ...`. Any language can write one. DXF works too.
2. **The `musacad` command runs without a window.** `musacad --check` opens a drawing and reports problems. `musacad --plot` prints it to PDF. Neither needs a screen, so they work on servers, in scheduled jobs and in build pipelines.
3. **Clear answers for programs.** Every run ends with an exit code that a script can test, and `--check --json` gives a report a program can read.
4. **The libraries can be linked.** Musa CAD is LGPL-licensed C++, so your own tool can link its libraries to load, change and plot drawings directly.

There is no macro language inside the program (no AutoLISP or VBA). Work happens outside it: a program writes the drawing, and Musa CAD checks and prints it. For most automation this is simpler and goes further, because the program can use any language, any data source and any library.
