This is the whole ribbon as Musa CAD builds it, read from the program itself when this wiki is built. Each button links to the page of the command it runs. Where a button has a drop-down, its entries are listed under it.

Tools shown <s>crossed out</s> are on the ribbon but greyed out, because Musa CAD does not have them yet. They sit where AutoCAD has them, so you know where they will be.
