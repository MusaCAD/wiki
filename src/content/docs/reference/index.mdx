Every command in Musa CAD is listed here. Type part of a name, an alias or a word from the description in the box below, and the table narrows down. For example, `REC` finds RECTANG, and `dim` finds every dimension command. Click a command to open its page.

Each page shows what Musa CAD itself reports about the command: how to type it, where it is on the ribbon, what it asks first, and the release it arrived in. Pages that also have a written explanation, with a worked example and the differences from AutoCAD, are marked **Complete** or **Partial**. The fifty commands people use every day are written first; [Coming from AutoCAD](/get-started/coming-from-autocad/#your-everyday-commands) lists them by kind of work. The rest are being added.
