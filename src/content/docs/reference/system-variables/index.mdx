A system variable is a setting with a name, like `PICKBOX` (the size of the pick box) or `OSMODE` (which object snaps are on). To change one, type its name and press <kbd>Enter</kbd>. Musa CAD shows the current value in angle brackets and asks for a new one:

```musacad
Command: PICKBOX
Enter new value for PICKBOX <10>: 6
```

You can also use `SETVAR`, which asks for the variable's name first. `SETVAR ?` lists the variables it knows.

The **Starts as** column is the value a fresh install begins with. It is read from Musa CAD itself when this wiki is built. Some variables are kept between sessions, some with each drawing, and some only until you close the program; each variable's page will say which as the pages are written.
