A `.musa` file is Musa CAD's own drawing format. It is plain text: you can open one in any text editor and read it. Each line is one record, such as a layer, a line, a circle or a dimension. The first line says which version of the format the file uses, for example `MUSACAD 45`, and the last line is `END`.

## Which files open where

The rule is simple:

- **Newer Musa CAD always opens older files.** A file from version 0.1.0 opens in every later release.
- **Older Musa CAD cannot open newer files.** When a release adds something to the format, files saved by it need that release or newer. An older release says `Unsupported file format version` and does not open the file.

So if you share drawings with someone, check that they have the same Musa CAD version as you, or a newer one.
