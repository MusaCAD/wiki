| Format | Read | Write | Notes |
|---|---|---|---|
| `.musa` | Yes | Yes | Musa CAD's own format. Plain text. |
| `.dxf` | Yes | Yes | Built in, nothing to install. |
| `.dwg` | Yes | Yes | Through the free ODA File Converter, which Musa CAD downloads for you from **DWG Setup**. |
| PDF | No | Yes | Plot or export. Real vector output. |
| PNG, JPEG, BMP, TIFF, GIF | As images in a drawing | No | Attach with `IMAGEATTACH`. |

When Musa CAD imports a file, it tells you anything it could not bring across, instead of dropping it silently.
