| Format | Read | Write | Notes |
|---|---|---|---|
| `.musa` | Yes | Yes | Musa CAD's own format. Plain text. |
| `.dxf` | Yes | Yes | Built in, nothing to install. Writes AutoCAD R2000 files. |
| `.dwg` | Yes | Yes | Through the free ODA File Converter, which Musa CAD downloads for you from **DWG Setup…** in the application menu. Writes AutoCAD 2018 files. |
| PDF | No | Yes | Plot or export. Real vector output. |
| PNG, JPEG, BMP, TIFF, GIF | As images in a drawing | No | Attach with `IMAGEATTACH`, linked or embedded. |
| `.pgp` | Yes | Yes | Command aliases, including AutoCAD's `acad.pgp`. Load with `ALIASEDIT`. |

When Musa CAD imports a file, it tells you anything it could not bring across, instead of dropping it silently.
